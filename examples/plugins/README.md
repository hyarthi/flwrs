# Example plugins

**Demos only. They aren't published, versioned or supported.** Each one shows, in as little code as possible, a flwrs plugin written in another language. They all implement the same thing: an HTTP sink that sends one request per event.

| Folder | Language | Protobuf code | Build |
|---|---|---|---|
| [`http_sink_python_example`](http_sink_python_example) | Python 3 (stdlib `urllib`) | generated by `grpcio-tools` | `pip install grpcio-tools && ./build.sh` |
| [`http_sink_go_example`](http_sink_go_example) | Go (`net/http`) | generated by `protoc` + `protoc-gen-go` | `./build.sh` |
| [`http_sink_node_example`](http_sink_node_example) | TypeScript on Node.js ≥ 23.6 (`fetch`) | loaded at run time by `protobufjs` | `./build.sh` |
| [`http_sink_java_example`](http_sink_java_example) | Java 21+ (`java.net.http`) | generated by the Maven build | `./build.sh` (needs Maven) |

Each `build.sh` writes a plugin package to `dist/`, ready to upload:

```sh
curl -F file=@dist/http-sink-python-example-0.0.1.zip http://localhost:8080/api/plugins
```

At run time the server's host needs the language's runtime: `python3` with `protobuf` (`requirements.txt`), `node` or `java`. The Go package is a native binary for the machine it was built on.

**Payload** (`schema/in.json`, the same in all four): `url`, `method` (default `POST`) and `body`, all strings. Use an edge mapping to fill them in from a source's events.

**What each example does** (see README.md, *Plugin protocol*):

- reads `--id`, `--host`, `--port` (and `--token`, else `FLWRS_TOKEN`), connects to the hub and sends `Initialize` with the version from `manifest.json` and the schema from `schema/in.json`;
- frames every message (`u32` LE packet length, `u32` LE header length, `Version` / `Msg-Code` header lines, protobuf body) and checks the `Msg-Code` of what it receives;
- sends an HTTP request for each `SinkEvent`, one at a time, and reports failures as an `ErrorEvent`;
- answers `Shutdown` (which is also how the hub rejects a plugin) with `Exit` and exits;
- reconnects with the same `Initialize` if the connection drops (1 s, doubling up to 30 s).

Left out on purpose: `LogEvent`s (stdout and stderr already go to the server log), launch arguments, log levels and a proper HTTP client configuration.
